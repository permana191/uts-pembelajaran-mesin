Formulasi Matematis Algoritma

1. Multiple Linear Regression (MLR): Memodelkan emisi CO2 sebagai kombinasi linier dari vektor fitur hasil One-Hot Encoding dan atribut numerik mesin:

ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ + ε

2. Random Forest Regressor (Ensemble Bagging): Mengagregasi rata-rata prediksi dari B = 60 pohon keputusan regresi (CART) yang dilatih pada sampel bootstrap untuk menangkap interaksi non-linier antar jenis bahan bakar:

ŷ_RF(x) = (1 / B) · Σ_{b=1}^{B} T_b(x)

3. Metrik Evaluasi Regresi:

R² = 1 - [ Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)² ]
RMSE = √[ (1/n) · Σ(yᵢ - ŷᵢ)² ]

Temuan Kritis Pra-Pemrosesan Data

  • 1. Eliminasi 1.103 Baris Duplikat (14,94%): Dataset mentah berisi 7.385 baris survei multi-tahun. Penghapusan duplikat mencegah kebocoran evaluasi (data leakage) antara data latih dan data uji.
  • 2. Penanganan Anomali Fuel Type 'N' (Natural Gas): Hanya ditemukan 1 observasi (Chevrolet Impala Dual Fuel) pada seluruh dataset sehingga dieliminasi demi stabilitas stratifikasi.
  • 3. Efek Stoikiometri Pembakaran: Bahan bakar Diesel memiliki rasio emisi 26,89 g CO2 per L/100km, lebih curam dibanding Bensin (23,31) dan Ethanol E85 (16,32). Interaksi kemiringan berbeda inilah yang membuat Random Forest unggul 32,6% lebih rendah galat RMSE-nya dibanding MLR.
